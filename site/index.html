What File Explorer leaves out

Everything here is in the app you download, at no cost.

Every folder's size, in the list

File Explorer keeps folder sizes in Properties. Glint shows them in the Size column as the folder opens, so you can sort by them.

See what's filling your drive

A map of any folder, like WizTree's, with colors for what grew in the last day, week or month.

Any file on any drive, as you type

Turn on instant search and Glint indexes your NTFS drives the way Everything does, then keeps up with every change.

Tabs, and two panes side by side

Copy and move between two folders, or compare them down through every subfolder and sync them.

Thumbnails that never hold up the folder

1,200 photos are on screen in 9.3 ms, and their thumbnails fill in right after from Windows' own cache.

Quick Look on Space

See any file full size without opening it: code, pictures, video, PDFs, Office documents, and tables you can query with SQL.

Search inside files

ripgrep in any folder, with regular expressions and replace, and the text in PDFs and Office documents, by words or by meaning.

Ctrl+K for everything

Jump to the folders you use most by typing a few of their letters, or run any command.

The tools Explorer doesn't have

Find duplicates by their content, see what's locking a file, check a download's checksum, clear out old build output, and rename many files at once with Undo.

Still Windows

Windows' own file engine

Copy, move, delete and rename run on the engine File Explorer uses: its progress, Replace or Skip, the Recycle Bin and administrator prompts.

Works with File Explorer

Drag and drop and the clipboard work both ways, and if you turn it on, File Explorer's right-click menu opens folders in Glint.

Archives open like folders

Zip, 7z, RAR, cabinet and tar archives open in the list or the grid, and nothing is extracted until something needs a file.

And more: Git status in every folder, a terminal under the files, comparing files and folders, the Recycle Bin with Undo, sending files to another PC, S3, WebDAV and SFTP as folders, folder rules, and a search box over every drive from any app (Ctrl+Alt+F). Everything Glint does

Questions

Is Glint free?

Yes. It's open source under the MIT license, with no ads and no account.

Why does Windows say it protected my PC?

Glint's installer isn't code-signed yet, and Windows warns about programs it hasn't seen many people run. Choose More info, then Run anyway. All of Glint's code is on GitHub, every update is signed and checked before it installs, and each download's SHA-256 is on its release page. On a PC with Smart App Control on, Windows doesn't run unsigned programs at all, so Glint can't run there until its installer is signed.

Does it collect any data?

No. There's no telemetry and no analytics: on its own, Glint only asks GitHub whether there's a new version. Privacy policy

How does it update?

When a new version is out, Glint says so. Install downloads it, checks its signature and restarts into it in a few seconds.

What does instant search need?

Nothing until you turn it on. Then a small service reads each NTFS drive's file table once, the way Everything does, and follows its change journal, so Windows asks for administrator approval one time. It knows names, sizes and dates, never what's inside files, and answers only the accounts that turned it on (and administrators). How it works

Does it replace File Explorer?

No, it runs next to it. Copy, paste and drag and drop work between the two, and File Explorer can open folders in Glint if you turn that on. To remove Glint, uninstall it from Settings → Apps, which takes instant search out too.

How is it different from Everything or WizTree?

Everything and WizTree showed that reading the NTFS file table directly is the fast way, and Glint's index does the same. The difference is that it's inside a whole file explorer: folder sizes in every list, a disk map, tabs and two panes, previews, and Windows' own file operations.

Which Windows does it run on?

Windows 10 and 11, 64-bit. Glint draws its window with WebView2, which Windows 11 has built in; the installer adds it to a PC that doesn't have it.
